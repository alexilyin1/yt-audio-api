🎵 Set up Spotify

✓ Spotify is already set up. You can enter new keys below to replace them.

To get song recommendations we need a free Spotify "key". It takes about 3 minutes and only has to be done once.

  1. Open the Spotify Developer Dashboard and log in with your normal Spotify account (a free account is fine). Accept the terms if asked.
  2. Click Create app.
  3. Fill in the form:
    • App name: anything, e.g. My Music Helper
    • App description: anything, e.g. Personal use
    • Redirect URI: http://127.0.0.1:5000/callback then click Add
    • Which API/SDKs: tick Web API
    Tick the terms box and click Save.
  4. On your new app's page, click Settings. You'll see your Client ID.
  5. Next to it, click View client secret to reveal the Client secret.
  6. Copy both and paste them below.
🔒 Your keys are stored only in a file on this computer (.env) and are never shown again or shared.
